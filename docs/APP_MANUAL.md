# EduOS 使用手册

本手册面向机构 Admin、教务、财务、老师、学生和家长。EduOS 是同一套系统、同一个登录入口，登录后由服务器根据角色返回对应页面和数据。

## PWA 安装

1. 打开 `https://eduos.study-go.top/login`。
2. 在 Chrome 或 Edge 地址栏点击安装图标，或打开浏览器菜单选择“安装应用”。
3. 所有人安装的是同一个 EduOS。Admin、老师、学生、家长登录后看到不同页面。
4. 浏览器决定安装后的入口位置。Windows 上通常可以在开始菜单搜索 `EduOS`。
5. 如果安装后找不到桌面图标，可以在开始菜单右键 EduOS，选择固定到任务栏；也可以打开文件位置后创建桌面快捷方式。

## 登录与账号

- Admin 可以在“账号”页面为老师、学生和家长创建账号。
- 老师只能为自己授权班级内的学生开通账号。
- 账号拥有者可以在“系统设置”或移动端“我的”页面修改自己的密码。
- Admin 可禁用、启用或按安全策略删除账号。删除采用软删除：保留审计和业务历史，停用登录与租户身份。

## Authenticator

- 高权限账号应使用 Authenticator 动态验证码。
- 入口：`系统设置 -> 安全中心 -> 绑定 Authenticator`。
- EduOS 不会在页面、日志或文档中展示 TOTP secret、恢复码明文或服务器密钥。
- 如果服务器缺少 MFA 加密配置，绑定页面会提示需要补齐环境变量，不会生成二维码。

## 存储与备份

- 课程资源、附件、视频和图片走 OSS 私有存储。
- 前端不能直连 RDS，也不能持有 OSS AccessKey。
- 资源下载必须先通过服务端 RBAC 和 tenantId 校验，再生成 signed URL。
- Admin 本地备份只同步核心结构化数据，不同步作业照片、错题照片、视频、附件、token、密码哈希或 MFA secret。

## 版本信息

当前阶段 EduOS 由服务器统一部署。管理员在服务器执行 `git pull`、构建和 PM2 重启后，所有用户刷新页面即可使用新版本。

用户端不需要下载单独更新包。如果页面长时间停留在旧版本，请关闭 EduOS 窗口后重新打开。

## 常见问题

### 安装后找不到桌面图标

这是浏览器控制的行为，不是 EduOS 代码可以强制决定的。请在 Windows 开始菜单搜索 EduOS，然后固定到任务栏或创建桌面快捷方式。

### 学生是否能看到 Admin 数据

不能。EduOS 的安全边界在服务端。学生账号请求 Admin、老师端、财务或其他学生数据时，服务端会拒绝。

### 老师是否能看到财务数据

不能。老师端只显示自己的课程、班级、学生、作业、资源、错题和活动进度，不返回财务后台数据。

### 忘记密码怎么办

账号拥有者可在登录后修改自己的密码。无法登录时，由 Admin 在账号页处理账号状态并重置后续流程。
