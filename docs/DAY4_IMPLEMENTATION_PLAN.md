# Day 4 实施计划

日期：2026-05-21

## 原则

- 不新增高风险依赖。
- 不修改生产环境。
- 不执行 production migration。
- 不读取或提交真实密钥。
- 不牵动 Admin 端侧边栏布局。
- 优先修复学生端和老师端低风险体验问题。

## 执行步骤

1. 写入审查文档和功能缺口。
2. 修复移动端底部导航 active 状态。
3. 调整学生端/老师端底部导航结构，加入“我的”。
4. 新增学生端“我的”页面。
5. 新增老师端“我的”页面。
6. 优化 `MobileShell` 宽度、safe area、通知入口。
7. 增加学生/老师权限边界测试和移动导航测试。
8. 更新业务闭环和权限矩阵文档。
9. 运行 `pnpm lint`、`pnpm typecheck`、`pnpm test`。
10. 自审后提交，并尝试推送。

## 暂不实施

- 真实生产 migration。
- OSS/RDS 真实写入 smoke test。
- 独立桌面壳。
- 真实短信、微信、支付接口。
- 大规模 UI 重写。
