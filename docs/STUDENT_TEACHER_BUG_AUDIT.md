# 学生端与老师端 Bug 审查

日期：2026-05-21

## 已确认并本轮修复

1. 移动端底部导航 active 状态固定在首页。
   - 影响：用户进入课表、作业、错题、班级等页面时仍看到首页高亮。
   - 修复：导航改为按当前 pathname 判断 active。

2. 学生端/老师端缺少“我的”入口。
   - 影响：个人信息、版本、帮助、退出登录不可见，体验像半成品。
   - 修复：新增 `/student/me` 与 `/teacher/me`。

3. 移动端壳子在桌面访问时过窄。
   - 影响：老师在电脑上看教学端时页面像手机预览，不利于备课和批改。
   - 修复：主内容最大宽度扩大，底部导航保留移动优先但适配桌面。

## 已检查未发现 P0

- 学生角色权限中没有 `route:teacher`、`route:dashboard`、`route:finance` 或 `finance:*`。
- 老师角色权限中没有 `route:dashboard`、`route:finance` 或 `finance:*`。
- 学生课表、作业、错题、资源查询均使用 `tenantId` 和当前学生身份/班级授权过滤。
- 老师课表、作业、班级、资源查询均使用 `tenantId` 和当前老师身份/授权班级过滤。
- service worker 只缓存 app shell 和公共静态资源，不应缓存敏感 API。

## 发现但不在本轮大改

1. 活动入口不够集中。
   - 建议：Day 5 增加学生活动页和老师活动进度页。

2. 课程详情页还不够完整。
   - 建议：把点名、资源、作业、反馈整合成老师上课页；学生侧做课程详情页。

3. 移动端组件未完全统一。
   - 建议：逐步替换为 `components/mobile/*` 共享组件。

4. e2e 覆盖仍不足。
   - 建议：补深链越权、跨 tenant、资源下载、作业提交/批改全流程。

## 风险等级

- P0：暂无。
- P1：移动端导航 active 错误、缺“我的”入口、桌面移动端过窄。
- P2：活动页、课程详情页、统一组件、更多 e2e。
