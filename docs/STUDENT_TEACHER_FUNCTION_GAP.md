# 学生端与老师端功能缺口

日期：2026-05-21

## 学生端

已完成或已有基础：

- 学习工作台
- 我的课表
- 作业列表、提交、订正状态
- 错题本与订正
- 授权资源库
- 学情报告
- 通知
- 支付流水只读

本轮补齐：

- 新增“我的”入口，用于个人信息、版本、帮助、缓存策略说明和退出登录。
- 底部导航恢复为学习任务 App 结构。

后续缺口：

- 独立活动/打卡页面，展示单词打卡、连续打卡、历史记录。
- 课程详情页需要进一步整合本节课内容、资源、作业、反馈。
- 附件上传体验需要更明确的大小/类型限制提示。
- 本地缓存清理按钮目前先作为入口和说明，后续需要和 PWA 缓存策略联动。
- 学情报告需要更多真实趋势图和老师阶段建议。

## 老师端

已完成或已有基础：

- 教学工作台
- 我的课表
- 班级学生概览
- 作业布置、提交查看、批改、订正
- 教学资源上传/绑定
- 课程资源和课后反馈
- 通知

本轮补齐：

- 新增“我的”入口，用于教师档案、账号安全、版本、帮助和退出登录。
- 底部导航恢复为教学执行 App 结构。

后续缺口：

- 独立活动进度页，展示班级单词打卡完成率和未完成名单。
- 课程详情页应进一步合并点名、资源、作业、课后反馈和课堂表现。
- 班级学生详情页需要更完整的出勤、作业、错题、活动进度。
- 老师端资源发布仍需更清晰地显示“可发布班级”和“不可发布原因”。
- 老师端不应看到财务详情，后续 e2e 需要覆盖深链访问。

## 不做的事情

- 不拆成学生/老师/Admin 三套系统。
- 不引入大型 UI 库。
- 不执行 production migration。
- 不用假数据伪装真实业务完成。
