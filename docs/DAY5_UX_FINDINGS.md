# Day 5 UX Findings

日期：2026-05-21

## 已修复

- 学生资源详情不再直接暴露旧 `fileUrl`。
- 支付流水页补齐退费申请和审批入口。

## P1 体验问题

- 学生端缺少独立课程详情页，课表到课程内容、资源、作业、反馈的路径还不够顺。
- 老师端课程详情/上课页还不够集中，点名、资源、作业、反馈分散。
- 活动系统缺少学生端活动页和老师端活动进度页。
- 订单/续费还没有专门向导，仍容易让财务和教务在报名/支付页面之间跳转。

## P2 优化

- 表格页可以继续增加更明确的 empty state 下一步动作。
- 财务报表需要筛选、导出说明和对账状态。
- 权限拒绝页可增加“返回对应端首页”的角色化按钮。
