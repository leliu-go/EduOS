# 学生端 / 老师端 / Admin 端业务闭环对齐

日期：2026-05-21

## 总体原则

EduOS 仍然是一套系统、多角色登录。Admin 负责管理和监督，老师负责教学执行，学生负责学习任务和反馈。三类端共享同一套课程、班级、排课、作业、错题、资源、活动和学情数据，但入口、字段和操作权限严格不同。

## 排课闭环

- Admin / 教务：创建课程、班级、排课和教室资源安排。
- 老师端：只看到自己的课程、班级和学生数，可进入教学执行页。
- 学生端：只看到自己所属班级/课程的课表，不显示完整教室占用和其他学生。
- 权限：查询必须包含 `tenantId`，老师以 `teacher.userId` 或授权班级过滤，学生以 `student.userId` 和班级关系过滤。

## 考勤与打卡闭环

- 老师端：对本人课程点名、确认学生打卡、写课后反馈。
- 学生端：查看自己的上课状态和可用打卡入口。
- Admin / 教务：查看全局考勤和课消状态。
- 权限：学生只能提交自己的打卡，老师只能处理本人课程。

## 作业闭环

- 老师端：布置作业、查看未提交、批改、要求订正。
- 学生端：查看待提交、提交作业、查看批改结果、提交订正。
- Admin / 教务：监督作业完成和批改状态。
- 权限：学生提交必须绑定自己的学生档案；老师只能管理本人班级/授权学生。

## 错题闭环

- 老师端：从作业或课堂反馈中标记错题，绑定知识点和错因。
- 学生端：查看自己的错题、提交订正、查看掌握状态。
- Admin / 教研：看统计和薄弱知识点趋势。
- 权限：学生不能读取其他学生错题，老师不能读取非授权学生错题。

## 资源闭环

- Admin / 教研：管理机构资源、课程资料、题单、单词书和视频。
- 老师端：在授权班级和课程中使用/发布教学资源。
- 学生端：只查看已授权资源和课程绑定资源。
- 权限：前端不得拼接私有 OSS 地址；资源下载必须先通过后端 `tenantId + RBAC + 归属` 校验，再返回 signed URL 或安全下载接口。

## 活动闭环

- Admin / 教务：创建并发布活动，第一阶段为 `WORD_CHECKIN`。
- 老师端：查看自己班级活动进度和未完成名单。
- 学生端：完成自己的打卡任务。
- 权限：老师不能修改全局活动规则，学生不能看其他学生隐私。

## 学情闭环

- 老师端：写课后反馈，标记需关注学生。
- 学生端：查看自己的出勤、作业、错题、资源和老师建议。
- Admin：查看汇总和运营风险。
- 当前状态：已有报告入口和基础数据；趋势图、阶段报告、老师建议模板仍为后续计划。
