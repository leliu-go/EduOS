# EduOS Frontend Design System

Date: 2026-05-22

## Style Direction

EduOS should feel like a modern education operations product: calm, credible, efficient, and friendly enough for students and teachers.

## Layout Rules

- Admin: left sidebar, sticky topbar, clear page header, dense but scannable cards/tables.
- Teacher: mobile-first teaching execution, bottom nav, quick actions, task-first cards.
- Student: learning task app, bottom nav, clear daily priorities, no internal operation data.
- Parent: child-centered summary and read-only progress surfaces.

## Visual Tokens

- Primary: current EduOS teal primary token.
- Accent: soft warm accent for guidance and low-risk highlights.
- Success: emerald.
- Warning: amber.
- Danger: red/destructive token.
- Neutral: muted slate/gray.

## Component Rules

- Buttons use icons for concrete commands.
- Cards use consistent padding and titles.
- Badges communicate state, not decoration.
- Empty/error/loading states are part of the page, not afterthoughts.
- Avoid page-level decorative gradients or generic SaaS hero layouts.
